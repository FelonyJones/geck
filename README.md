# Gec(k) - Godot Editor Console

Gec is a console that exists in the editor context to assist with development of whatever.\n
It is capable of running functions, evalutating expressions in gdscript, and running Godot scripts.

I made it to help me develop some level editor tools for my game.
It is usable to me, however it was not designed with users other then me in mind so your mileage may vary.
